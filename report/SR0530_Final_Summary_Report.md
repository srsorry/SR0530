## 三、讨论与判读

1. **LMM 最敏感点 vs ML 最佳预测点**：
   - 若两者出现在相近偏心率，说明 AL-密度关联在该区域既统计显著又具有可预测性，适合作为最终研究靶点。
   - 若两者错位，可能提示该区域的关联主要由不可预测的个体变异或非线性因素驱动。

2. **过拟合评估**：
   - 学习曲线中训练 R² 与验证 R² 的差距反映模型泛化能力。
   - 验证 R² 随样本量增加仍呈上升趋势，提示增加样本量可能进一步提升泛化性能。

3. **特征重要性**：
   - SHAP summary 与 permutation/builtin 重要性共同提示：**Axial length (mm)** 是预测密度的核心特征。
   - 其他特征（ACD、Age、SE、Gender）的贡献相对较小，但在特定模型/方案中仍有稳定信号。

4. **数据组差异**：
   - strict 数据组剔除局部 ROI 异常值，结果更稳健；lenient 数据组保留更多样本，但可能混入异常。

## 四、结论与建议

1. **推荐研究靶点**：综合 LMM 敏感性与 ML 预测性能，**1.5 mm** 是当前数据下最值得深入分析的距离。
2. **推荐模型**：**Random_Forest**（方案 A2_Biomechanical_NoK，strict 数据），Test R² = 0.557。
3. **后续方向**：
   - 在推荐距离上进一步扩大样本量，验证学习曲线显示的潜在提升空间。
   - 探索 AL 与密度关系的非线性形式（如样条、分段回归），以解释 LMM 与 ML 峰值可能存在的错位。
   - 若需与 linear density（cones/mm²）口径对照，可补充 linear density 的 LMM 与 ML 分析。
