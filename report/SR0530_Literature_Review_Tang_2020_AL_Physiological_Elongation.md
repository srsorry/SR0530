# 文献阅读笔记：Tang et al. 2020

> **原文**：Tang T, Yu Z, Xu Q, Peng Z, Fan Y, Wang K, et al. A machine learning-based algorithm used to estimate the physiological elongation of ocular axial length in myopic children. Eye Vis (Lond). 2020;7:50. doi: 10.1186/s40662-020-00214-2.
>
> **本地 PDF**：`orgData/Tang et al. - 2020 - A machine learning-based algorithm used to estimate the physiological elongation of ocular axial len.pdf`

---

## 一、研究背景与核心问题

- **临床痛点**：眼轴长度（AL）增加并不总等于近视进展。儿童在生长发育过程中会经历“生理性眼轴增长”（∆AL_Phy），这部分增长可被晶状体屈光力下降所代偿，不引起等效球镜（SER）变化。
- **应用场景**：角膜塑形镜（ortho-K）配戴者停药 3–4 周后才能准确验光，因此临床上希望仅通过 AL 变化来评估真实近视进展，但需要扣除生理性增长部分。
- **研究目标**：利用机器学习方法，基于常规横断面临床数据，估计中国学龄近视儿童的生理性眼轴增长速率。

---

## 二、研究方法

### 2.1 数据来源

- **研究设计**：单中心回顾性横断面研究。
- **样本量**：1011 名 6–18 岁近视儿童（男性 491，女性 520）。
- **纳入标准**：SER 0 ~ −8.00 D，散光 ≤ 3.00 D，无眼病、无 ortho-K 史。
- **测量设备**：
  - AL：IOL Master（非接触部分相干激光干涉仪）
  - 角膜地形图参数：SIRIUS SYSTEM
  - 睫状肌麻痹验光：0.5% 复方托吡卡胺滴眼液
- **数据选择**：仅取右眼数据。

### 2.2 输入/输出变量

- **输入变量**：Age、Sex、K-mean（平均角膜曲率）、CCT（中央角膜厚度）、WTW（白到白角膜直径）、SER（等效球镜）。
- **排除变量**：ACD（前房深度）。作者认为 ACD 随年龄显著变化，引入会导致共线性问题，且未提升预测性能。
- **输出变量**：AL（眼轴长度，mm）。

### 2.3 建模流程

1. 先用 6 种机器学习算法预测 AL：
   - Linear Regression
   - Robust Linear Regression
   - SVM（linear / quadratic / cubic kernel）
   - Bagged Trees
2. 采用 **5-fold CV** 划分训练/验证集。
3. 选择最佳模型预测 AL。
4. **估计生理性增长**：固定 SER、K-mean、CCT、WTW、Sex，得到 AL_predicted–age 曲线，再对 age 求偏导数 ∂AL/∂Age，得到不同年龄下的生理性 AL 年增长速率。

### 2.4 主要结果

- **最佳模型**：Robust Linear Regression。
  - R² = 0.87
  - R = 0.928
  - RMSE = 0.378 mm
  - MAE = 0.293 mm
- **多元线性回归基线**：R² = 0.81。
- **生理性 AL 增长速率**：
  - 6 岁：男性 0.066–0.116 mm/年，女性 0.060–0.110 mm/年。
  - 18 岁：男性 0.010–0.045 mm/年，女性 0.003–0.038 mm/年。
  - 随年龄线性下降；SER 越负（近视越深）或 K-mean 越小，生理性增长越快。

## 三、优点

| 优点 | 说明 |
|------|------|
| **样本量大** | 1011 例，超过多数儿童近视预测研究。 |
| **临床易获取参数** | 仅使用年龄、性别、SER、K-mean、CCT、WTW 等常规检查指标，便于推广。 |
| **问题定义新颖** | 不满足于预测 AL，而是尝试从 AL 总增长中拆分出“生理性”与“病理性”部分。 |
| **对 ortho-K 随访有实际价值** | 在无法验光时，可用模型估计生理性增长，辅助判断真实近视控制效果。 |
| **预测精度较高** | Robust Linear Regression R² = 0.87，优于传统多元线性回归。 |
| **使用交叉验证** | 5-fold CV 在一定程度上防止过拟合。 |
| **模型可解释性强** | 最佳模型为线性模型，系数和偏导数具有直接临床解释。 |

## 四、局限与缺点

| 缺点 | 说明 |
|------|------|
| **横断面设计** | 用横断面数据推断个体纵向生长曲线，本质上是“合成队列”，无法反映真实个体轨迹。 |
| **单中心、单一种族** | 北京大学人民医院就诊人群，结论外推至其他地区/种族需谨慎。 |
| **仅右眼数据** | 忽略双眼差异及双眼相关性。 |
| **ACD 被排除** | ACD 在生理代偿机制中具有理论重要性，但因共线性被剔除，可能损失信息。 |
| **“生理性增长”是理论构造** | 模型假设 SER 不变时的 AL-年龄偏导即为生理性增长，未与真正的非进展性近视纵向数据对照验证。 |
| **缺少外部验证集** | 仅内部 5-fold CV，未在独立队列中验证泛化能力。 |
| **机器学习标签略显夸张** | 最佳模型为稳健线性回归，与传统回归差异不大；“ML”更多体现为算法筛选框架。 |
| **示意图参数固定较随意** | 展示曲线时固定 CCT=550 μm、WTW=12 mm，未充分讨论这些假设对估计的影响。 |
| **未与文献基准比较** | 未将估计值与 Tideman、Mutti 等纵向研究中的生理性增长数值进行系统比较。 |

## 五、对本项目的启示

1. **AL/K 作为复合指标的启发**：Tang 等通过 K-mean 与 AL 的交互来解释代偿性增长，提示 AL 与角膜曲率的比值（AL/K）可能比单独 AL 更能概括眼形态与近视进展的关系。
2. **预测 ≠ 机制解释**：该文用线性模型即可达到高 R²，说明 AL 与这些参数关系近似线性；复杂的非线性模型并未带来提升，这与我们在 SR0530 中观察到线性模型（Lasso/ElasticNet/Ridge）表现稳健的现象一致。
3. **横断面 ML 的局限性**：若本项目未来希望估计“生理性”vs“病理性”成分，需要纵向数据或明确的无进展对照组，不能仅依赖横断面预测。
4. **临床转化价值**：Tang 的方法展示了如何把 ML 预测结果（AL_predicted）进一步加工成临床指标（生理性增长速率），这对我们将密度预测模型结果转化为可解释的生物标志物具有参考价值。
