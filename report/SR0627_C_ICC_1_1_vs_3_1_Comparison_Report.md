# SR0627_C_ICC_1_1_vs_3_1_Comparison 报告

> **目标**：明确当前 LMM 使用的 ICC 类型，并与 ICC(1,1)、ICC(3,1) 进行比较。

> **数据**：lenient 数据集（71 眼 / 46 subjects），每个偏心率独立拟合。

---

## 一、ICC 类型说明

### 当前 LMM 使用的 ICC

当前 `SR_LMM_revised.py` 中的 ICC 计算公式为：

```
ICC = σ²_Subject / (σ²_Subject + σ²_Residual)
```

模型结构为：

```
Angular cone density ~ AL + Age + SE + Gender + K + ACD + Eye + (1 | Subject)
```

其中 **Subject 是随机效应**，**Eye (OD/OS) 是固定效应**。
这对应于 **ICC(3,1) 的思路**：受试者随机、测量方式（眼别）固定，
在控制了 Eye 的固定差异后估计受试者间的一致性/可重复性。

但由于还额外加入了 AL 等协变量，当前 ICC 是一个**条件 ICC**。
在本数据中，AL、SE 等协变量解释了相当一部分受试者间变异，
导致 σ²_Subject 下降，因此 Current ICC 通常低于无条件的 ICC(3,1)。

### ICC(1,1) vs ICC(3,1) 定义

| 类型 | 模型 | 解释 | 适用场景 |
|------|------|------|---------|
| **ICC(1,1)** | `y ~ 1 + (1 | Subject)` | 单因素随机模型；残差包含眼别差异和测量误差 | 把每只眼视为独立的随机测量，不考虑 OD/OS 系统差异 |
| **ICC(3,1)** | `y ~ Eye + (1 | Subject)` | 两因素混合模型；Eye 固定，残差为去除眼别均值后的误差 | 认为 OD/OS 是固定因子，估计受试者间一致性 |
| **Current LMM** | `y ~ covariates + Eye + (1 | Subject)` | 在 ICC(3,1) 基础上进一步控制协变量 | 评估“控制 AL 等因素后”的受试者间一致性 |

## 三、关键发现

1. **ICC(1,1) 与 ICC(3,1) 数值接近**：
   两者差异很小，说明在本数据中 OD/OS 眼别对密度的系统影响并不大。

2. **Current ICC 明显低于 ICC(1,1) / ICC(3,1)**：
   当前 LMM 加入了 AL、SE、Age 等协变量，这些协变量解释了部分受试者间的变异，
   导致随机截距方差 σ²_Subject 大幅下降，从而 ICC 降低。
   因此当前 ICC 是一个**条件 ICC**：表示“在控制协变量后”，剩余变异中受试者间变异所占比例。

3. **类型归属**：当前 LMM 的结构（Subject 随机 + Eye 固定）在概念上对应 **ICC(3,1)**，
   但由于还加入了协变量，它不应与无条件的 ICC(3,1) 直接比较。

4. **报告建议**：
   - 若讨论“双眼测量值的受试者内一致性/可重复性”，报告 **ICC(3,1)**。
   - 若讨论“控制眼形态后仍由受试者解释的变异比例”，报告 **Current ICC**。
   - 不建议把 Current ICC 与 ICC(1,1) 混为一谈。
