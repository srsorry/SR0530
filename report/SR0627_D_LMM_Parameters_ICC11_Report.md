## 二、列名说明

| 后缀 | 含义 |
|------|------|
| `_Beta` | 标准化回归系数（带符号） |
| `_P` | 对应参数的 P 值 |
| `_AbsBeta` | 标准化回归系数的绝对值 |
| `_RelBeta` | 相对系数 = |Beta| / Σ|Beta| |
| `R2_Marginal` | 固定效应解释的变异比例 |
| `R2_Conditional` | 固定效应 + 随机效应解释的变异比例 |
| `ICC_1_1` | 按 ICC(1,1) 计算的受试者间一致性 |
| `VarRandom_1_1` | ICC(1,1) 模型的受试者随机截距方差 σ²_random |
| `VarResidual_1_1` | ICC(1,1) 模型的残差方差 σ²_residual |

> 注：VarRandom_1_1 与 VarResidual_1_1 单位为原始 Angular cone density (cones/deg²) 的平方。
