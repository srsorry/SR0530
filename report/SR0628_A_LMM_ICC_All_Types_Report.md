# SR0628_A_LMM_ICC_All_Types 报告

> **目标**：整理当前 LMM 各参数的 P 值、绝对系数、相对系数，R²（边际/条件），
以及 ICC(1,1)、ICC(2,1)、ICC(3,1) 和当前 LMM ICC 的方差分量。

> **数据**：lenient 数据集（71 眼 / 46 subjects）。

> **当前 LMM**：`Angular cone density_z ~ AL_z + Age_z + SE_z + Gender + CC_z + ACD_z + Eye + (1|Subject)`

> **相对系数**：`|Beta| / Σ|Beta|`，反映固定效应内部的相对重要性。

## 一、ICC 模型说明

| 类型 | 模型 | σ²_random | σ²_residual | 说明 |
|------|------|-----------|-------------|------|
| ICC(1,1) | `y ~ 1 + (1|Subject)` | 受试者随机截距 | 残差 | 单因素随机模型，不考虑 Eye 系统差异 |
| ICC(2,1) | Subject、Eye 均为随机 | 受试者方差 | 眼别方差 + 误差 | 两因素随机模型；眼别方差通过 ANOVA 方法 of moments 估计，负值截断为 0 |
| ICC(3,1) | `y ~ Eye + (1|Subject)` | 受试者随机截距 | 残差 | 两因素混合模型，Eye 固定 |
